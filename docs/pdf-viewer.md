# PdfViewerPro

`PdfViewerPro`는 PDF를 읽고 검색하고 양식을 채우는 뷰어입니다.
별도 진입점 `@mega-ui/react/pdf-viewer`와 `@mega-ui/react/pdf-viewer.css`로 제공하며,
Apache-2.0 라이선스의 [pdf.js](./pdfjs-license.txt)(`pdfjs-dist` 6.3)를 렌더링 엔진으로 사용합니다.
기본 진입점에는 포함하지 않으므로 이 화면에서만 엔진을 내려받습니다.
기존 `PDFViewer`는 브라우저 내장 뷰어를 그대로 쓰는 가벼운 컴포넌트로 유지합니다.

```tsx
import { PdfViewerPro } from '@mega-ui/react/pdf-viewer';
import '@mega-ui/react/pdf-viewer.css';
// Vite 기준. 워커 주소는 번들러에 맞게 전달합니다.
import workerSrc from 'pdfjs-dist/build/pdf.worker.min.mjs?url';

function Reader() {
  return (
    <PdfViewerPro
      source="/reports/2026-q3.pdf"
      name="2026-q3.pdf"
      label="분기 보고서"
      workerSrc={workerSrc}
    />
  );
}
```

## API

| prop                 | 계약                                                                                                      |
| -------------------- | --------------------------------------------------------------------------------------------------------- |
| `source`             | 필수. URL 문자열, `Uint8Array`, `ArrayBuffer`, `Blob`/`File`, 또는 `null`. 바이트는 복사해서 사용         |
| `label`              | 영역 이름. 기본 PDF 문서                                                                                  |
| `name`               | 내려받기·저장에 쓰는 파일 이름. 기본 document.pdf                                                         |
| `onSave(bytes,name)` | 선택적 비동기 저장. 입력한 양식 값을 포함한 PDF 바이트를 전달. 없으면 저장 버튼 대신 내려받기만 제공      |
| `password`           | 암호화 문서의 비밀번호. 없으면 화면에서 입력받음                                                          |
| `defaultPage`        | 처음 표시할 쪽. 기본 1                                                                                    |
| `defaultZoom`        | 숫자 배율 또는 `fit-width`(기본) · `fit-page`                                                             |
| `showTools`          | 기본 true. 상단 탐색·확대·검색·저장 도구 표시                                                             |
| `workerSrc`          | `pdfjs-dist/build/pdf.worker.min.mjs`의 주소. 생략하면 pdf.js가 메인 스레드에서 해석해 큰 문서에서 느려짐 |
| 네이티브 div 속성    | ref·className·style·id·이벤트 전달. children 제외. 영역 role·이름은 뷰어가 지정                           |

## 기능과 범위

- **렌더링·탐색**: 세로로 이어지는 쪽 보기, 화면 근처의 쪽만 캔버스로 그립니다. 쪽 번호 입력·이전/다음·썸네일 클릭으로 이동하고,
  스크롤 위치에 따라 현재 쪽 번호를 갱신합니다. 화면 배율(devicePixelRatio)을 반영해 최대 2배까지 선명하게 그립니다.
- **확대·회전**: 폭 맞춤·쪽 맞춤·±25% 단계(0.25~4배)와 90° 회전. 컨테이너 크기를 8px 단위로 반올림해 스크롤바로 인한 재계산을 막습니다.
- **검색·텍스트 선택**: 모든 쪽의 텍스트에서 대소문자를 구분하지 않고 찾아 건수와 위치를 표시하고, 해당 쪽으로 이동해 테두리로 표시합니다.
  텍스트 레이어로 마우스 선택·복사가 가능합니다. **낱말 단위 하이라이트는 제공하지 않고 쪽 단위로 표시**하며, 최대 500건까지 찾습니다.
- **주석·양식**: pdf.js 주석 레이어로 링크·팝업 주석을 표시하고 AcroForm 입력 칸을 실제 입력 요소로 그립니다.
  입력한 값은 문서 저장에 포함합니다. 화면 상단에 입력 칸과 서명 칸 개수를 알립니다.
- **글자·서명·도장 넣기**: `editable`이 true면 주석 도구를 제공합니다.
  - `글자 넣기`는 누른 자리에 텍스트 주석(FreeText)을 만듭니다. 바로 입력하고 Escape로 끝냅니다.
  - `서명·그리기`는 끌어서 그린 선을 잉크 주석(Ink)으로 남깁니다. 손으로 쓴 서명이 여기에 해당합니다.
  - `도장 넣기`는 PNG·JPEG·WebP·GIF 이미지를 골라 도장 주석(Stamp)으로 현재 쪽 가운데에 넣습니다.
  - 만든 주석은 끌어서 옮기고 모서리로 크기를 바꿉니다. 색 선택은 글자와 그리기에 적용합니다.
    `주석 삭제`는 선택한 주석을, `실행 취소`·`다시 실행`은 주석 편집 기록을 되돌립니다.
  - 세 종류 모두 문서 저장·내려받기에 포함되어 다른 PDF 뷰어에서도 보입니다.
- **서명 칸**: 문서에 있는 서명 필드는 **위치만 표시**하며, 서명을 검증하거나 암호학적 전자서명을 만들지 않습니다.
  `서명·그리기`로 남긴 그림은 잉크 주석이며 전자서명이 아닙니다.
- **저장·재열기·인쇄·내려받기**: 저장과 내려받기는 `saveDocument()`가 만든 바이트를 사용하므로 입력한 양식 값이 남습니다.
  같은 바이트를 다시 `source`로 넘기면 값이 그대로 열립니다. 인쇄는 숨긴 iframe에 문서를 띄워 브라우저 인쇄 창을 엽니다.
- **오류 처리**: 비밀번호가 필요하면 입력 폼을 보여 주고 틀리면 다시 묻습니다. 손상된 파일과 PDF가 아닌 파일은 이유를 알립니다.
  한 쪽을 그리지 못해도 나머지 쪽은 계속 볼 수 있습니다.

## 제공하지 않는 것

암호학적 전자서명 생성·검증, 페이지 추가·삭제·회전 저장, 목차(outline)·첨부 파일 패널, XFA 양식,
텍스트 낱말 단위 하이라이트, 하이라이트 주석, 대체 텍스트 편집, 서버 저장·권한 관리는 제공하지 않습니다.
암호화 문서는 비밀번호 입력만 다루며 문서의 권한 플래그(인쇄 금지 등)를 강제하지 않습니다.

## 검증 범위

- `tests/browser/pdf-viewer.spec.ts`: 2쪽 문서 렌더링·썸네일·쪽 이동, 확대·쪽 맞춤·회전, 텍스트 레이어 내용,
  전체 쪽 검색과 결과 표시, 양식 입력 후 저장·저장 실패/재시도·저장본 재열기, 손상 파일 오류, 내려받기,
  글자·서명·도장 주석을 만들어 저장한 파일에 FreeText·Ink·이미지가 들어갔는지 확인, 주석 삭제와 실행 취소,
  카탈로그 카드, 다크 390px 레이아웃.
- 픽스처: `tests/fixtures/make-pdf.mjs`가 만드는 2쪽 문서·AcroForm 문서·손상 파일·도장 이미지. 문서 사이트의 예제도 같은 파일을 사용합니다.
- 암호화 문서는 만들 도구가 없어 자동 검사에 포함하지 않았습니다. 비밀번호 흐름은 코드 경로만 구현했고 실제 파일로 검증하지 않았습니다.
- 실제 스크린 리더 낭독, 모바일 하드웨어 터치, 인쇄 대화상자, 대용량(100쪽 이상) 문서의 성능은 수동 검증하지 않았습니다.

### 실행 기록 · 2026-09-10

Node 24.18.0, macOS arm64, Playwright의 Chromium·Firefox·WebKit, Vite 개발 서버, 2 workers.
위 21개 검사(3개 브라우저 × 7)가 통과했습니다. 라이트 1280px과 다크 390px 화면에서 도구 모음·썸네일·쪽 보기를 확인했습니다.
