# Charts

`@mega-ui/react/charts`의 **[ChartPro](#chartpro)**는 로드맵 전체 유형·시간/이중 축·드래그 탐색·PNG/SVG/CSV를 제공합니다.

기존 `CartesianChart`는 막대·선·영역과 누적 막대·누적 영역을, `PieChart`는 원형·도넛을 제공합니다.
기존 `BarChart`·`LineChart`·`Sparkline` API는 유지합니다. 기존 SVG 구현과 ChartPro의 Apache ECharts 엔진 모두 기존 컨트롤·색상 토큰을 사용하고, 전용 JS/CSS를 별도 진입점으로 배포합니다.

```tsx
import '@mega-ui/react/styles.css';
import '@mega-ui/react/charts.css';
import { CartesianChart, createChartCsv } from '@mega-ui/react/charts';

const data = {
  labels: ['7월', '8월', '9월'],
  series: [
    { id: 'online', label: '온라인', values: [510, -80, 640] },
    { id: 'store', label: '매장', values: [null, 330, 390] },
  ],
};

<CartesianChart
  data={data}
  label="월별 손익 비교"
  type="line"
  xLabel="월"
  yLabel="손익 (만원)"
/>;

const csv = createChartCsv(data, '월');
```

## API

| API / prop                             | 계약                                                                                                                            |
| -------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| `CartesianChartData.labels`            | 입력 순서의 범주 이름 `readonly string[]`. 최대 200개. 날짜도 등간격 범주로 표시하며 시간 간격 계산이나 정렬을 하지 않음        |
| `CartesianChartData.series`            | `readonly ChartSeries[]`, 최대 6개                                                                                              |
| `ChartSeries`                          | 고유 `id`, 표시 `label`, 범주 수와 정확히 같은 길이의 `values: readonly (number \| null)[]`, 선택적 `tone`                      |
| `tone`                                 | `brand / success / warning / danger / teal / purple`. 미지정 시 계열 순서대로 색 배정                                           |
| `data`, `label`                        | 필수 데이터와 figure의 접근 가능한 이름·표시 제목                                                                               |
| `type`                                 | `bar`(기본), `line`, `area`. 선과 영역은 직선 연결                                                                              |
| `xLabel`, `yLabel`                     | 축·데이터 표 설명. 기본 `항목`, `값`. 단위 변환 없이 이름만 지정                                                                |
| `formatValue`                          | `(value: number) => string`. 표·툴팁·축의 전체 값 설명. 기본 한국어 숫자 형식, 최대 유효숫자 21자리. 시각적 축 눈금은 축약 표기 |
| figure 속성                            | `ref`, `id`, `style`, `className` 등 네이티브 figure 속성 전달. `children`은 받지 않음                                          |
| `createChartCsv(data, categoryLabel?)` | 검증된 전체 데이터를 CSV 문자열로 반환. 기본 첫 열 제목 `항목`. 잘못된 데이터에는 예외 발생                                     |

`stacked?: boolean`은 막대·영역을 양수/음수별로 누적합니다(기본 false). `line`에서는 무시합니다.
`range?: ChartRange`는 0부터 시작하는 `[시작 인덱스, 끝 인덱스]`이며 끝 항목도 포함합니다.
`onRangeChange?(range)`로 제어형 상태에 연결합니다. range만 전달하면 구간 컨트롤은 읽기 전용입니다.
range를 생략하면 내부 상태로 관리하며 최초에는 전체 구간입니다. 유효 범위 밖의 인덱스는 보정하고,
비정상 숫자는 전체 구간으로 처리합니다. 데이터 교체 시 범주는 인덱스 기준으로 유지합니다.
`showRangeControls?: boolean`은 구간 도구 표시 여부이며 기본 true입니다.

이름·id는 공백만으로 구성할 수 없으며 각각 최대 200 UTF-16 코드 단위입니다.
범주 이름 중복은 허용하고 위치로 구분합니다. 계열 id 중복, 배열 길이 불일치,
문자열 숫자, 희소 배열, 상한 초과는 거부합니다. 컴포넌트는 원시 예외 대신 데이터 형식 오류를 표시합니다.
조회·로딩·서버 오류·재시도는 소비 앱에서 관리합니다. 전달 데이터는 수정하지 않습니다.

## 값·탐색·내보내기

- 모든 계열이 공통 선형 Y축을 사용하고 0을 포함합니다. 계열을 숨겨도 축 범위는 유지합니다.
  음수 막대는 0 아래로 내려가며, 0은 최소 1px 표식으로 표시합니다. 이중 축은 없습니다.
  누적 모드에서는 표시 중인 계열만 양수/음수별로 더하고 축을 다시 계산합니다. 합계가 숫자 범위를 넘으면 오류로 처리합니다.
  누적 영역은 값의 부호가 바뀌는 지점에서 끊어 교차 영역을 만들지 않으며, 단일 점은 점 표식으로 남깁니다.
- `null`·`NaN`·무한대는 결측값입니다. 막대·점은 생략하고 선은 끊으며 표·툴팁은 `값 없음`, CSV는 빈 셀입니다.
  전부 결측 또는 빈 데이터이면 `표시할 값이 없어요.`를 표시합니다.
- 범례 버튼은 계열 표시를 토글하며 `aria-pressed`와 취소선으로 상태를 알립니다.
  선은 색과 대시 패턴으로 구분합니다. 막대의 묶음 순서는 범례 순서와 같으며 색 구분이 어려우면 값 안내·표로 비교할 수 있습니다.
- 차트는 Tab 진입점 하나를 사용합니다. 좌우 방향키, Home·End로 항목을 옮기고 Enter·Space로 값 안내를 열며 Esc로 닫습니다.
  포인터로 가리키거나 항목을 선택해도 값 안내를 표시합니다. 안내는 차트 아래에 유지하며 다음 항목 선택 또는 Esc로 바뀝니다.
- 구간 도구의 시작·끝 슬라이더, 확대·축소·이전/다음·전체 구간 버튼으로 조회 범위를 조절합니다.
  키보드 탐색도 표시 구간 안에서 이동합니다. 데이터 표·CSV는 구간 밖 항목까지 원본 전체를 유지합니다.
  확대는 항목 수를 줄이는 범주 탐색이며 시간축 확대나 마우스 드래그 줌은 아닙니다.
- 좁은 화면과 많은 항목은 차트 내부에서 가로 스크롤합니다. 긴 범주 이름은 축에서 줄이고 전체 이름은 값 안내·표에 유지합니다.
- 전체 데이터 표는 네이티브 details로 열며 숨긴 계열도 포함합니다. CSV도 전달받은 모든 계열을 포함하고 표시 형식과 무관하게 원시 숫자를 사용합니다.
- CSV는 UTF-8 BOM·CRLF·따옴표 이스케이프를 사용합니다. 텍스트의 수식 접두어 앞에는 작은따옴표를 붙이고 숫자 음수는 숫자로 유지합니다.
  파일 생성 실패는 다시 내려받을 수 있는 오류로 표시합니다. 다운로드 완료·디스크 저장 성공을 주장하지 않습니다.

## PieChart

```tsx
import { PieChart } from '@mega-ui/react/charts';

<PieChart
  label="판매 채널 비율"
  variant="donut"
  valueLabel="건"
  data={[
    { label: '온라인', value: 120 },
    { label: '매장', value: 80 },
    { label: '파트너', value: 40 },
  ]}
/>;
```

`PieChartProps`는 필수 `label`, `data: readonly PieChartDatum[]`와 선택적 `variant: 'pie' | 'donut'`(기본 pie),
`valueLabel`(기본 값), `formatValue`, figure 네이티브 속성·ref를 받습니다.
각 항목은 `label`, `value: number | null`, 선택적 `tone`(CartesianChart와 동일)입니다. 최대 24개 항목을 지원합니다.
음수는 오류로 거부하며 null·NaN·무한대는 결측, 0은 비율 0으로 유지합니다. 양수가 하나도 없으면 빈 상태를 표시합니다.
큰 수의 합이 넘치지 않도록 정규화한 비율로 각도를 계산하며, 한 항목 100%도 온전한 원·도넛으로 표시합니다.
비율은 소수점 한 자리로 반올림하므로 표시 비율의 합은 100%와 조금 다를 수 있습니다.

조각은 Tab 또는 좌우/Home/End로 탐색하고 Enter·Space·클릭·터치로 선택합니다.
범례 버튼은 선택한 항목을 강조하며 데이터를 숨기거나 비율을 다시 계산하지 않습니다.
색을 구분하기 어려워도 전체 항목별 이름·값·비율과 표를 읽을 수 있습니다. CSV는 비율이 아닌 원시 값을 내보냅니다.

## 예제·검증 범위

컴포넌트 목록의 **그리드·편집기·차트** (`/#components/professional`)에
DataGridPro·TextEditor·CartesianChart·PieChart의 조작 가능한 데모·API 링크·전체 예제 링크를 제공합니다.
이름으로 글로벌 검색이 가능하며 `?to=CartesianChart` 또는 `?to=PieChart`로 바로 이동합니다.
전문 엔진은 이 카탈로그를 열 때 지연 로드합니다.

`/#charts?full=1`에서 판매 채널별 손익을 조회하고, 막대·선·영역·누적 전환 → 범례 선택 →
항목 탐색 → 전체 표 → CSV 다운로드를 검증합니다. 조회 실패 예제의 재시도는
로컬 예시로 돌아가는 동작이며 실제 서버 요청은 아닙니다. 다운로드는 브라우저가 담당하고 CSV 재반입은 지원하지 않습니다.

- `tests/charts.test.mjs`: 음수·0·동일 값·단일 값·극단적 숫자, 결측, 입력 거부, CSV 원시값·수식 방어·인용, SSR, 기본 진입점 격리, CSS 토큰.
- `tests/browser/charts.spec.ts`: Chromium·Firefox·WebKit에서 키보드·툴팁·범례·표·CSV·내보내기 실패 후 재시도·빈 결과·조회 실패 후 재시도.
  390px 화면, dark, reduced motion과 가로 넘침·버튼 크기를 검사하고 스크린샷을 남깁니다.
  Chromium·WebKit은 터치 에뮬레이션의 tap, Firefox는 포인터 클릭으로 항목 선택을 검사합니다.
- 성능 목표: 200개 범주 × 6개 계열에서 표시 500ms 미만, 키보드 탐색 200ms 미만.
  표시 측정은 이미 열린 예제에서 데이터 교체 후 두 animation frame까지이며 최초 네트워크 로딩은 제외합니다.
  키보드는 첫 항목에서 마지막 항목으로 이동 후 두 frame까지 측정합니다. 초기 화면 로딩·전체 스크롤 처리량 보장은 아닙니다.
- 실제 모바일 터치 장치, 스크린 리더 낭독, 모든 로케일의 수동 검증은 남아 있습니다.

## ChartPro

로드맵 전체 유형과 전문 탐색에는 `ChartPro`를 사용합니다. 기존 `CartesianChart`·`PieChart`는 위 계약으로 유지합니다.
Apache ECharts 6.1(Apache-2.0)의 모듈을 별도 charts 진입점에서 사용하며 기본 UI 진입점으로 가져오지 않습니다.
[엔진 API](https://echarts.apache.org/en/api.html)와 [이벤트/액션](https://apache.github.io/echarts-handbook/en/concepts/event/)을 기반으로 구현했습니다.
엔진 옵션이나 HTML 툴팁을 직접 전달받지 않고, 아래 데이터에서 그림·표·CSV를 함께 생성합니다.

```tsx
import {
  ChartPro,
  createChartProCsv,
  type ChartProData,
} from '@mega-ui/react/charts';
import '@mega-ui/react/charts.css';

const data: ChartProData = {
  type: 'line',
  xAxis: 'time',
  series: [
    {
      id: 'sales',
      label: '매출',
      points: [
        [Date.UTC(2026, 8, 1), 100],
        [Date.UTC(2026, 8, 2), null],
        [Date.UTC(2026, 8, 5), 160],
      ],
    },
  ],
};
<ChartPro
  label="일별 매출"
  data={data}
  timeZone="Asia/Seoul"
  yAxes={[{ label: '만원' }]}
/>;
const csv = createChartProCsv(data, { timeZone: 'Asia/Seoul' });
```

### 데이터 유형

`ChartProData`는 `type`으로 구분되는 유니온입니다. 모든 배열은 readonly를 받으며 입력을 수정하지 않습니다.

| type                             | 데이터                                                                                                                                                                         |
| -------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `bar`, `line`, `area`, `scatter` | `series: {id, label, points: readonly [x, y][], axis?: 0 \| 1}[]`. `xAxis?: 'category' \| 'value' \| 'time'`. `stacked?: boolean`은 산점을 제외한 계열을 축별·양수/음수별 누적 |
| `pie`, `donut`                   | `items: {label, value: number \| null}[]`. 음수·중복 이름 거부, 0 비율 유지                                                                                                    |
| `heatmap`                        | `xLabels`, `yLabels`, `cells: readonly [xIndex, yIndex, value][]`. 중복 좌표·범위 밖 인덱스 거부                                                                               |
| `treemap`                        | `nodes: ChartTreeNode[]`. 노드는 고유 `id`, `label`, `value?`, `children?`. 부모 값 생략 시 자식 합계. 지정한 값은 자식 합계와 같아야 함                                       |
| `candlestick`                    | `candles: {time, open, close, low, high, volume: number \| null}[]`. OHLC 캔들+거래량 별도 패널·공유 시간 구간                                                                 |

- 범주 X는 이름 문자열, 수치/시간 X는 유한한 숫자입니다. 산점은 동일 X에 여러 Y를 허용합니다.
  나머지 계열의 X는 계열 안에서 중복할 수 없습니다. 산점 기본 X축은 value, 나머지는 category입니다.
- 시간은 epoch milliseconds이며 각 계열/캔들 안에서 엄격한 오름차순입니다. 날짜 문자열 추측·자동 정렬을 하지 않습니다.
  시간 간격을 실제 비율로 그립니다. 로컬 표시와 별도로 CSV·표에 정확한 UTC ISO 시각을 유지합니다.
- `null`·NaN·무한대 Y는 결측으로 정규화합니다. 선을 연결하지 않고 CSV는 빈 셀, 표는 `값 없음`입니다.
  OHLC는 모두 유한해야 하며 `low ≤ open/close ≤ high`, 거래량은 0 이상이어야 합니다.
- 값의 절댓값은 `1e100` 이하, 시간은 JavaScript Date 범위입니다. 이름/id는 1~200 UTF-16 길이이며 공백만인 이름은 거부합니다.
  최대 전체 10,000개 데이터, 20개 계열, 원형 200개 항목, 히트맵 각 축 1,000개, 트리 10,000개 노드/깊이 16(루트 0)입니다.
  트리 표는 부모와 자식 값을 모두 보여주므로 전체 행 값을 다시 합산하지 마세요.
- 입력 형식 오류는 안전한 오류 문구로 표시합니다. 순환 트리·중복 id·희소 배열·지원 상한 초과도 거부합니다.
  실제 데이터 집계·샘플링·서버 요청은 소비 앱이 담당합니다.

### 조작과 내보내기

- 네이티브 범례 버튼이 계열/원형 항목 표시를 토글합니다. 툴팁은 HTML을 실행하지 않는 텍스트 렌더링입니다.
- 좌표 차트에서 기본 드래그는 X구간 이동, Ctrl+휠은 확대/축소입니다. **드래그로 확대**는 사각 구간의 X범위를 확대하고,
  **드래그로 선택**은 사각 영역 안의 데이터 행을 선택합니다. Escape로 드래그 모드를 끝냅니다.
  구간 버튼과 시작/끝 슬라이더는 포인터 드래그의 키보드 대안입니다. 시간축에서도 같은 방식으로 동작합니다.
- 캔들 가격·거래량 패널은 같은 시간 구간을 사용합니다. 금융 구간 선택은 가격 패널의 캔들 행을 기준으로 합니다.
  원형에는 축 확대를 제공하지 않습니다. 트리맵은 노드 클릭 확대·드래그 이동·휠 확대와 전체 트리 복귀를 제공합니다.
- 차트 Tab 진입 후 좌우/상하·Home/End로 원본 데이터 값을 읽고 Enter/Space로 선택합니다.
  표의 체크박스로도 모든 항목을 선택할 수 있습니다. 숨긴 계열과 구간 밖 데이터도 원본 탐색·표·CSV에는 남습니다.
- 표는 100행 단위 페이지이며 전체 데이터가 생략되지 않습니다. CSV 전체/선택을 명시적으로 구분하고
  수식 접두어·따옴표·줄바꿈은 기존 안전한 CSV 규칙으로 처리합니다.
- PNG(2배 해상도)와 SVG는 현재 구간·범례 상태를 반영하고 제목·범례를 포함합니다. 이미지 최소 너비는 640px입니다.
  생성 실패는 실제 재시도 버튼인 다운로드 액션을 유지합니다. 디스크 저장 완료를 주장하지 않습니다.
- ResizeObserver와 테마 변경을 반영하며 언마운트 시 엔진·관찰자를 해제합니다. 애니메이션은 기본 사용하지 않습니다.
  서버 렌더링은 제목·표·컨트롤을 제공하고 그림은 클라이언트에서 생성합니다.
